# راهنمای استقرار و دیپلوی ربات کتابخوارشو با داکر (Docker)

این پوشه و فایل‌های داکر پروژه برای اجرای ایزوله، پایدار و بروزرسانی خودکار ربات در سرور آماده شده‌اند.

---

## 🛠️ ۱. راه‌اندازی اولیه روی سرور (توسط مسئول سرور)

۱. **کلون کردن ریپازیتوری:**
```bash
git clone https://github.com/niniam102030-commits/KetabkharSho_bot.git
cd KetabkharSho_bot
```

۲. **ایجاد فایل تنظیمات `.env`:**
فایل نمونه را کپی کرده و اطلاعات واقعی (توکن بله و شناسه‌های ادمین) را وارد نمایید:
```bash
cp .env.example .env
nano .env
```

۳. **بیلد و اجرای کانتینر:**
```bash
docker compose up -d --build
```

۴. **مشاهده لاگ‌های زنده ربات:**
```bash
docker compose logs -f
```

---

## 🔄 ۲. بروزرسانی خودکار ربات (پس از هر تغییر در کدهای گیت‌هاب)

هر زمان که برنامه‌نویس کد جدیدی به برنچ `main` پوش کرد، مسئول سرور تنها کافی است اسکریپت دیپلوی را اجرا کند:

```bash
chmod +x docker/deploy.sh
./docker/deploy.sh
```

یا دستورات زیر را دستی اجرا کند:
```bash
git pull origin main
docker compose up -d --build
```

---

## 💾 ۳. امنیت داده‌ها و دیتابیس (Volumes)
- دایرکتوری `./data` روی دیسک اصلی سرور ذخیره می‌شود، بنابراین با ری‌استارت شدن، خاموش شدن سرور یا بیلد نسخه جدید داکر، دیتابیس کاربران و سوابق چله به هیچ وجه پاک نخواهد شد.
- لاگ‌ها در `./logs/` ذخیره می‌گردند.
